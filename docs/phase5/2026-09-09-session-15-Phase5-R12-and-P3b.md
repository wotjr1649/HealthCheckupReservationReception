### 7.1 이번 회차가 실제로 물린 함정 넷

`[X]` **python `utf-8-sig` 로 쓰면 BOM 없던 파일에 BOM 이 붙는다.** 봉인 파일 넷을 포함해 열한 개에

```python
raw = io.open(p, "rb").read()
bom = raw.startswith(b"\xef\xbb\xbf")
s   = (raw[3:] if bom else raw).decode("utf-8")
...
io.open(p, "wb").write((b"\xef\xbb\xbf" if bom else b"") + s.encode("utf-8"))
```

`[X]` **봉인 문서의 §번호를 적기 전에 그 절이 실재하는지 확인하라.** `06` §21.2·§15.2 를 §32.1·§32 로
